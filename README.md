# Coursework_02

## Описание
Проект сбора данных о воздушных пространствах и самолетах тех стран, которые вы выберете.

## Установка

  poetry install

## Настройки

1. Настройки для фильтрации данных будут доступны при запуске main.py
2. Файл с итоговыми данными в формате json находится в data/data.json.
